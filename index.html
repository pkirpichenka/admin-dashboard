FAD · Бонусы по порогам

Убирает математическое ожидание премий. В прогнозе остаются только реальные суммы: 0 / 50 / 120 / 300 / 350 / 400 BYN для каждого закреплённого администратора (по актуальной шкале). Остальные разделы FAD не меняются.

Файл будет создан только после проверки 10 точных изменений. При несовпадении версии ничего не сохранится.
Исходник запрашивается с публичного GitHub pkirpichenka/admin-dashboard. Файл обрабатывается в браузере; ключи и данные никуда не отправляются. Для ручного режима интернет не нужен.
